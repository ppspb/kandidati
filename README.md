3-го избирательного округа (выборы депутатов Законодательного Собрания Санкт-Петербурга
VIII созыва, голосование **18–20 сентября 2026**) так, чтобы **каждое утверждение
подкреплялось источником**.

## Округ №3

Петроградский район (МО: Аптекарский остров, Введенский, Кронверкское, Петровский,
Посадский, Чкаловское) + Приморский район (МО: Ланское, частично Озеро Долгое).
Число избирателей — 151 818.
В 2021–2026 округа принадлежала В. Макарову (ушёл в Госдуму); мандат в 2021 г.
удержал М. Лабынёва (самовыдвиженец), в кампании 2026 г. она не участвует.

## Структура репозитория

- `docs/istochniki.md` — **аудит источников**: откуда собирать позиции и действия
  каждого кандидата (категории, конкретные URL, статус доступа, пробелы).
- `docs/svo_search_queries.md` — журнал широкого поиска по СВО: варианты ФИО,
  тематические группы, `site:`-запросы, результаты и правила атрибуции.
- `data/matriks.csv` — **матрица «утверждение → источник»** (главный файл;
  каждая строка: кандидат, тип, утверждение, дата, полный `source_url`, цитата,
  достоверность и уровень атрибуции).
- `data/candidates.json` — машиночитаемые профили кандидатов.
- `data/sources_catalog.csv` — машиночитаемый каталог источников.
- `scripts/check_sources.py` — локальная проверка полных URL и проверка доступности
  всех URL матрицы/каталога с подбором снапшотов Wayback Machine для мёртвых ссылок
  (запускать на машине с обычным интернет-доступом).

## Как читать матрицу

- `tip`: `взгляд` (заявление кандидата) / `поступок` (конкретное событие, действие) /
  `партийный контекст` / `биография` / `бизнес` / `кампания` / `контекст`.
- `uroven_atributsii`: один из фиксированных уровней — `личное высказывание`,
  `личное действие`, `партийная активность`, `СМИ-пересказ`, `не найдено`. Уровень
  `не найдено` используется для конкретной проверенной публикации, где кандидат не
  назван/не цитируется, а не как утверждение о всей его деятельности.
- `source_url`: полный URL конкретной страницы, подтверждающей строку; ссылки только
  на домен, `-` и пустые значения не допускаются.
- `doverie`: `прямая` — первоисточник (свои слова кандидата, официальный документ,
  реестр); `косвенная` — через СМИ/пересказ.
- `status`: `подтверждено` / `нужно уточнить` (пробелы помечены в столбце `zametka`
  и являются планом дальнейшей работы).

По СВО персональные записи добавлены для Гладунова и Зверева. Для Дудоладова и
Луговского в проверенных источниках персональное подтверждение не найдено; партийные
материалы СР/КПРФ вынесены в отдельные строки с уровнем `партийная активность` и
не приписываются кандидатам.
