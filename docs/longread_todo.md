## 10. Критерии готовности

Лонгрид можно считать готовым, если:

- [ ] читатель может пройти страницу сверху вниз без постоянного открытия карточек;
- [ ] восемь сравнительных вопросов остаются видимыми, но не поглощают весь материал;
- [ ] у каждого кандидата есть одинаковые подглавы;
- [ ] все 79 исходных тематических меток либо связаны с главой, либо явно отмечены как материал для следующего прохода;
- [ ] каждая опубликованная фактическая фраза имеет конкретный источник;
- [ ] личная позиция, действие партии, пересказ СМИ и официальный реестр визуально различаются;
- [ ] отсутствие найденной информации не превращается в оценку;
- [ ] страница удобна на мобильном и при печати;
- [ ] навигация остаётся лёгкой и не превращается в тяжёлое верхнее меню;
- [ ] `node --check app.js`, JSON/CSV-проверки, URL-проверка и mock-render проходят без ошибок.
