# Повторная проверка URL

Дата: 18.09.2026.

Команда:

```bash
python3 scripts/check_sources.py
```

Локальная проверка структуры перед сетевым проходом завершилась успешно:
`data/matriks.csv` и `data/sources_catalog.csv` содержат полный URL с непустым путём
в каждой строке; значения `-`, пустые ссылки и ссылки только на домен не прошли бы
проверку.

Сетевой проход собрал **66 уникальных URL** из матрицы и каталога. В рабочей
песочнице все запросы завершились кодом `0` из-за ограничения исходящего доступа;
Wayback-снапшоты в этом проходе также не вернулись. Поэтому `0/66` — это результат
сетевой среды агента, а не вывод о том, что страницы удалены. Страницы, использованные
для новых строк по СВО, дополнительно проверялись через поиск и просмотр страниц;
их конкретные адреса сохранены в `data/matriks.csv` и `data/sources_catalog.csv`.

Для повторной проверки с обычным интернет-доступом нужно запустить ту же команду;
для одной только структурной проверки используется:

```bash
python3 scripts/check_sources.py --syntax-only
```
