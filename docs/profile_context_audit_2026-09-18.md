# Повторная проверка индивидуального контекста кандидатов — 18.09.2026

## Зачем проведён второй проход

Сайт должен показывать не только сопоставимые ответы по единому вопроснику, но и более широкий индивидуальный контекст. Такой контекст нельзя автоматически превращать в общий балл: объём публичного материала, партийный статус и предпринимательские сведения имеют разные уровни атрибуции.

В публичный слой добавляются только записи с конкретным URL. Партийное выдвижение не используется как личная программа; отсутствие найденного материала формулируется как граница проверки.

## Как это представлено на сайте

- Слой «Сравнение» отвечает только на одинаковые вопросы и сохраняет пустые ячейки.
- Слой «Индивидуальные профили» показывает роли, деловой и партийный контекст, публичные каналы, отдельный аудит поиска и источники.
- Слой «Все записи и источники» показывает весь журнал матрицы, включая записи, которые пока не привязаны к вопроснику.
- Для каждого утверждения сохраняется конкретный URL; уровень атрибуции виден рядом с записью.
- Количество найденного материала не используется как преимущество кандидата.
